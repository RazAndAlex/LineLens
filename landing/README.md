# Landing page

A single self-contained page: `index.html` plus the four screenshots in `img/`.
No build step and no dependencies. Open the file to preview it.

To publish it on GitHub Pages, go to Settings → Pages, choose "Deploy from a
branch", and pick `main` with the `/landing` folder. The page then serves at
`https://razandalex.github.io/LineLens/`.

The screenshots are copies of the ones in `docs/screenshots/`, kept here so
this folder can be deployed on its own. If you retake them, replace both.
