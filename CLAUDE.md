# LineLens v2.5

## Agent skills

### Issue tracker

Issues live as markdown files under `.scratch/<feature>/` — this repo has no git remote, so no `gh`/`glab` CLI is used. See `docs/agents/issue-tracker.md`.

### Triage labels

Five default triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), each label string equal to its role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
